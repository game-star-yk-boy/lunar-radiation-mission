# Lunar Radiation Mission

A cinematic, educational 2D Moon mission built with Phaser 4.2.1.

## Run locally

From the workspace root:

```powershell
python radiation_1.py
```

Then visit `http://127.0.0.1:8000`.

## Controls

- Move: Arrow keys or WASD
- Mobile: On-screen left/right controls
- Interact: Walk into mission targets and choose an action when prompted
- Skip the opening cinematic: `Skip cinematic`

The radiation values are intentionally accelerated for gameplay and are not a real-world exposure model.
